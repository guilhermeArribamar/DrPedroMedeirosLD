# Landing Page — Dr. Pedro Medeiros | Apneia do Sono

Landing page responsiva em HTML, CSS e JavaScript, pensada para conversão e SEO.

## Estrutura
- `index.html`: estrutura, conteúdo, SEO on-page, Open Graph e dados estruturados.
- `style.css`: identidade visual, responsividade e componentes.
- `script.js`: máscara de telefone, formulário e CTA para WhatsApp.
- `assets/`: logo e foto fornecidas.

## Antes de publicar
1. Troque o `canonical` de `/apneia-do-sono/` pela URL final, se a página estiver em outro endereço.
2. Confirme com o cliente se o telefone `(11) 5039-2258` é o número de WhatsApp para leads.
3. Adicione favicon, `sitemap.xml` e `robots.txt` no domínio.
4. Configure Google Search Console e Analytics/Tag Manager.
5. Se o formulário for ligado a CRM, substitua a abertura do WhatsApp pela integração do CRM.
6. Revise o texto médico com o profissional responsável antes da publicação.

## SEO
A página inclui:
- título e meta description focados em "apneia do sono" e "pneumologista em São Paulo";
- H1 único;
- headings semânticos;
- conteúdo explicativo original;
- FAQ;
- dados estruturados `MedicalWebPage`, `Physician` e `FAQPage`;
- Open Graph;
- imagens com `alt`;
- boa estrutura para Core Web Vitals, sem bibliotecas JS externas.

## Observação médica
A copy evita prometer diagnóstico ou resultado. Os sintomas são apresentados como sinais que podem justificar avaliação profissional.
